# Баг-репорты: как хранятся и как их обрабатывать

Это инструкция для агента (и людей), которые сопровождают DarkArmy Dossier.
Пользователь нажимает кнопку **«БАГ»** рядом с ником, прикладывает скриншот и
описание. Записи видны в **Админка → Баги**.

## Где лежат данные

| Что | Где |
|---|---|
| Метаданные багов | SQLite, документ `bugs` (`src/storage.js`, `getDoc('bugs')`) |
| Скриншоты | `data/bug-reports/<id>.png` (или `.jpg`/`.webp`) — каталог в `.gitignore` |
| API | `src/routes/bugs.js` |
| UI | кнопка `#bugBtn` + модалка `#bugModal` (index), вкладка «Баги» в админке |

Формат элемента:

```json
{
  "id": "uuid",
  "user": "evgen",
  "description": "Текст бага",
  "page": "/index.html",
  "createdAt": "2026-11-25T19:00:00.000Z",
  "file": "uuid.png",
  "mime": "image/png"
}
```

## API

- `POST /api/bugs` — любой авторизованный: `{description, page, screenshot}`,
  screenshot — data URL PNG/JPG/WEBP до 3 МБ. Админам уходит уведомление.
- `GET /api/bugs` — только `admin`: список + `screenshotUrl`.
- `GET /api/bugs/:id/screenshot` — только `admin`: сам скриншот.
- `DELETE /api/bugs/:id` — только `admin`: удалить баг и его скриншот.

## Как агент обрабатывает баги

Пользователь может просто сказать: **«исправь баги»**.

1. Получить список. Варианты:
   - через API (нужна админ-сессия), либо
   - напрямую из SQLite:
     ```bash
     cd DarkArmyDossier
     node -e "const s=require('./src/storage');s.init({dir:'./data'});console.log(JSON.stringify(s.getDoc('bugs',{items:[]}),null,2));s.close();"
     ```
2. Для каждого бага: воспроизвести, исправить, прогнать `npm test`/`npm run check`
   и проверку сценария.
3. Удалить из списка (и скриншот) через `DELETE /api/bugs/:id` **после** проверки
   фикса, чтобы не потерять контекст, если исправление не удалось.
4. Если баг непонятен — оставить запись, уточнить у пользователя.
5. Не коммитить содержимое `data/bug-reports/` (данные пользователя, `.gitignore`).

## Замечания

- Скриншот не обязан быть: баг можно описать текстом.
- Если кнопки «БАГ» нет в шапке — обновите страницу (Ctrl+F5).
- Удаление бага необратимо, поэтому сначала фикс и проверка, потом `DELETE`.
