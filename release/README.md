# DarkArmy Dossier — сборки приложения

## Windows

**`DarkArmyDossier.exe`** (45 КБ) — портативный лаунчер для Windows 10/11.

- Запускает локальный сервер (`node server.js`), если он ещё не запущен.
- При первом запуске спрашивает адрес сервера в формате `ip:port` или `https://домен`
  и сохраняет его в `server.txt` рядом с exe. Это позволяет подключаться к любому
  удалённому серверу Dossier, а не только к локальному.
- Открывает Dossier в отдельном окне Edge/Chrome (`--app`), без адресной строки.
- Требуется установленный **Node.js** (только для локального сервера) и браузер Edge/Chrome.
- Сменить сервер: запустить `DarkArmyDossier.exe --setup` или отредактировать `server.txt`.

Просто запустите `DarkArmyDossier.exe`. Если сервер уже работает — откроется окно.

## Android

**`DarkArmyDossier.apk`** (54 КБ) — WebView-клиент.

- Подписан debug-ключом (для установки вручную; не для Google Play).
- При первом запуске спросит адрес сервера, например:
  - `https://dossier.example.com` — рекомендуемый вариант (PWA/микрофон/HTTPS);
  - `http://192.168.120.128:7561` — локальная сеть (без микрофона в браузере).
- Кнопка «Сервер» в верхней панели позволяет сменить адрес.
- Разрешения: интернет, сеть, микрофон.
- Для установки: передайте APK на телефон, откройте, разрешите установку из неизвестных источников.

> Для полноценного офлайн-режима и установки как PWA лучше открыть сервер по HTTPS
> в Chrome и нажать «Установить приложение». APK — тонкий клиент.

## Пересборка

- EXE: `powershell -ExecutionPolicy Bypass -File desktop/launcher/build-exe.ps1`
  (или вручную `csc` из `desktop/README.md`).
- APK: `python android/build.py` (нужны Android SDK + JDK 17+; пути можно задать
  через `ANDROID_SDK_ROOT` и `JAVA_HOME`).
