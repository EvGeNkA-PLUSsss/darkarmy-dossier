# DarkArmy Dossier — сборки приложения

## Windows

**`DarkArmyDossier.exe`** (~70 КБ) — портативный лаунчер для Windows 10/11
в тёмном фирменном стиле, без стандартных белых окон Windows.

- Отдельный тёмный экран подключения: вводишь `ip:port` или `https://домен`.
- Для порта `8443`/`443` автоматически выбирается HTTPS, для `7561` — HTTP.
- Адрес сохраняется в `server.txt` рядом с exe.
- «Локальный сервер» запускает `node server.js`, если он ещё не запущен.
- «Подключиться» открывает Dossier в отдельном окне Edge/Chrome (`--app`).
- Telegram для доступа/оплаты AI подтягивается с сервера (настраивается в админке).
- Требуется Node.js только для локального режима; для удалённого — только браузер.

## Android

**`DarkArmyDossier.apk`** (~29 КБ) — WebView-клиент с тёмным нативным экраном подключения.

- **Исправлен вылет:** в старую сборку не попадали inner-классы `MainActivity$*`
  (d8 собирал только `MainActivity.class`) — Android падал с `NoClassDefFoundError`.
  Теперь `build.py` включает все классы; APK проверен на наличие inner-классов в `classes.dex`.
- При первом запуске — тёмный экран: адрес сервера, кнопка «Подключиться».
- Плавающая кнопка «Сервер» поверх приложения позволяет сменить адрес.
- При ошибке сети показывает экран с причиной, а не закрывается.
- Подписан debug-ключом (ручная установка; для Google Play нужен свой keystore).
- **Перед установкой новой версии удалите старую** — versionCode 2, иначе Android
  может оставить старый кэш/подпись.
- Разрешения: интернет, сеть, микрофон.

> Для полноценного офлайн-режима и установки как PWA лучше открыть сервер по HTTPS
> в Chrome и нажать «Установить приложение». APK — тонкий клиент.

## Пересборка

- EXE: `powershell -ExecutionPolicy Bypass -File desktop/launcher/build-exe.ps1`
  (или вручную `csc` из `desktop/README.md`).
- APK: `python android/build.py` (нужны Android SDK + JDK 17+; пути можно задать
  через `ANDROID_SDK_ROOT` и `JAVA_HOME`).
