# Телефон, офлайн-режим и микрофон

## Установка приложения

- **Android**: откройте сайт по HTTPS в Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone/iPad**: Safari → «Поделиться» → «На экран Домой».
- **Windows**: Chrome/Edge → иконка установки в адресной строке, либо «?» → «Установить приложение».
- Готовый APK: `release/DarkArmyDossier.apk` — при первом запуске укажите адрес сервера.
- Готовый EXE: `release/DarkArmyDossier.exe` — запускает локальный сервер и открывает окно приложения.

## Офлайн-режим

1. Профиль (человечек) → «Офлайн-режим».
2. Включите «Скачивать проекты для просмотра без интернета».
3. Дождитесь сообщения «Скачано: N файлов, M проектов».
4. Без интернета приложение откроется, покажет проекты и файлы, но кнопки редактирования будут скрыты.
5. Отключите режим или нажмите «Очистить», чтобы удалить скачанные данные.

Требование: офлайн-кэш работает в secure context — HTTPS или localhost. По обычному HTTP в LAN service worker недоступен.

## Микрофон на HTTP

Браузеры разрешают микрофон (`getUserMedia`) только в secure context:
- HTTPS,
- `localhost` / `127.0.0.1`.

По `http://192.168.x.x` микрофон не заработает — это ограничение браузера, а не приложения.

Решения:
1. Открыть Dossier по HTTPS (встроенный HTTPS-порт 7562 или домен с Let's Encrypt).
2. Для LAN можно выпустить локальный сертификат (mkcert) и установить корневой сертификат на телефон.
3. Использовать бесплатный домен, указывающий на ваш IP (sslip.io, DuckDNS), и Let's Encrypt.
4. В крайнем случае — загрузить готовый аудиофайл в чат / использовать диктофон и вставить текст.

HTTPS-порт включается в `.env`: `HTTPS_PORT=7562`, `HTTPS_PFX`, `HTTPS_PFX_PASS`.
