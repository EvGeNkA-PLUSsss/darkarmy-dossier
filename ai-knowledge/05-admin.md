# Админ-панель

Открывается по `/admin.html` только для роли `admin`.

## Вкладки

- **Обзор** — состояние системы, БД, бэкапы, модели Ollama, экспорт/импорт метаданных.
- **Пользователи** — роли, смена пароля, удаление, наказания.
- **Приглашения** — коды регистрации, срок действия.
- **Наказания** — баны/мьюты, причины, снятие.
- **Журнал** — все изменения файлов с откатом (`POST /api/revert/:id`).
- **Настройки** — лимиты загрузки, регистрация, реклама, подписки.
- **Телеметрия** — события пользователей, устройства, сеть, последний IP/UA.
- **Darcus** — модели, промпты, стили, параметры генерации.
- **Реклама** — слоты и изображения.
- **Подписки** — коды и сроки.
- **Баги** — список баг-репортов; можно **редактировать описание и заменять скриншот**.
- **Голос** — настройки Silero TTS / Whisper.

## Баг-репорты

- Пользователь нажимает «БАГ», описывает проблему, прикрепляет PNG/JPG/WEBP до 3 МБ.
- Админ может открыть карточку, изменить текст, загрузить новый скриншот, сохранить (`PATCH /api/bugs/:id`).
- После исправления — удалить запись (скриншот тоже удаляется).

## Телеметрия

Собираются: экран, viewport, язык, часовой пояс, платформа, CPU, RAM, touch, тип сети,
тема, PWA-режим, IP, User-Agent. В списке пользователей показывается последнее устройство.
