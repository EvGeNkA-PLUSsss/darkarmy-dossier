# Типовые проблемы и решения

## Не открывается сайт

- Проверьте, запущен ли сервер: `npm start` / `start.bat`.
- Порт по умолчанию 7561; если занят — измените `PORT` в `.env`.
- Для доступа с телефона `BIND_HOST=0.0.0.0` и разрешите порт в брандмауэре.
- Проверьте `http://IP:7561/api/health` — должен вернуть `{"status":"ok"}`.

## Не работает Darcus

- Ollama запущена? `ollama list`, затем `ollama serve`.
- Модели скачаны? `ollama pull gemma4:e4b`, `qwen2.5vl:3b`, `nomic-embed-text`.
- Проверьте настройки в админке → Darcus.
- Если ответ пустой — повторите запрос или смените модель в конфиге.

## Darcus не создаёт файл

- Убедитесь, что проект открыт и у вас есть права редактора.
- Сформулируйте явно: «создай файл docs/guide.md и запиши туда …».
- Для больших документов используйте «создай реферат/документацию» — Darcus применит `generate_doc`.
- Если появилась красная плашка с ошибкой — прочитайте причину (нет прав, неверный путь, сессия).

## Микрофон не работает

- По HTTP браузер блокирует микрофон. Откройте HTTPS-адрес или localhost.
- Разрешите микрофон в настройках браузера/сайта.
- На Android/iOS нужен HTTPS с доверенным сертификатом.
- Проверьте кнопку «Микрофон» в чате и разрешение записи.

## Офлайн-режим

- Не включается/не скачивает: нужен HTTPS или localhost (Cache API/service worker).
- Скачалось не всё: проверьте статус в профиле; включите режим и нажмите «Скачать сейчас».
- Не открываются файлы: они не были скачаны; включите интернет и повторите.

## Совместное редактирование

- Оба пользователя должны иметь доступ к проекту.
- Открывайте файл в inline-редакторе, не в разных копиях.
- При конфликте побеждает последнее сохранение; при большой команде редактируйте по очереди.

## Ошибки БД / `database is locked`

- Не запускайте два сервера на одной `data/dossier.db`.
- Сделайте backup через админку или `npm run backup`.
- Проверьте права на каталог `data/`.

## HTTPS/домен

- Для Let's Encrypt нужен домен и открытые порты 80/443.
- Для IP без домена используйте sslip.io/DuckDNS; см. инструкцию по деплою.
