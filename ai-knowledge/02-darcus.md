# Как работать с Darcus

## Обычные вопросы

Пишите вопрос в поле «Спросите Darcus…». Darcus видит:
- историю последних сообщений;
- RAG-фрагменты из файлов доступных проектов;
- полное описание/OCR ранее прикреплённого к чату изображения;
- инструкции по самому приложению DarkArmy Dossier.

## Изображения

- Прикрепите изображение кнопкой скрепки.
- Сначала отвечает vision-модель: делает полное описание и распознаёт весь текст.
- Затем это описание сохраняется в контексте чата и доступно обычной модели для следующих вопросов.

## Голос

- Кнопка микрофона в панели чата (в обычном и Darcus-чате).
- Автоотправка распознанной речи включается кнопкой-самолётиком.
- Голосовой режим отвечает кратко (1–3 фразы).
- На телефоне микрофон работает только по **HTTPS** (или localhost). Если открыто по HTTP — браузер блокирует доступ; используйте HTTPS-адрес.

## Создание документов и файлов

Darcus обязан создавать файлы через ACTION, а не выводить их текстом в чат.

- `create` — небольшой файл с `path` и `content`.
- `edit` — изменить существующий файл.
- `mkdir` — создать папку.
- `delete`, `move`, `rename` — операции с файлами.
- `generate_doc` — большие документы: `path` + `prompt`, сервер сам генерирует Markdown (реферат, статья, документация).
- `open` — открыть файл в интерфейсе.
- `task` — создать задачу в проекте.
- `search` — открыть поиск с запросом.

После выполнения появляется кликабельная плашка. Если действие не выполнено — красная плашка с причиной.

## Что нельзя

- Нельзя редактировать файлы без прав редактора/создателя проекта.
- Нельзя выполнять ACTION в офлайн-режиме (только просмотр).
- Нельзя рассчитывать, что файл создастся, если модель не вернула ACTION; клиент страхует создание документов через `generate_doc`, но лучше просить явно: «создай файл docs/guide.md».

## Полезные формулы запросов

- «Найди в файлах проекта всё про … и дай ссылки на файлы».
- «Сделай краткое резюме файла …».
- «Создай реферат по … в файл docs/ref.md».
- «Открой файл …».
- «Поставь задачу: … исполнитель … срок …».
