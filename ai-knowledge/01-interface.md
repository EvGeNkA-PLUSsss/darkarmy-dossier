# Первые шаги в интерфейсе

## Вход и проекты

1. Открой адрес Dossier (например `https://dossier.example.com` или `http://IP:7561`).
2. Введи логин и пароль. Первого пользователя создаёт администратор через инвайт.
3. Слева — список проектов внизу панели. Выбери проект из выпадающего списка «ПРОЕКТ».
4. Дерево файлов — в левой панели. На телефоне она открывается кнопкой-гамбургером.

## Создание файла или папки

- Кнопка «Создать» → имя файла (по умолчанию `.md`). Файл создаётся в текущей папке.
- Кнопка «Папка» → имя новой папки.
- Перетащи файлы в область просмотра или нажми «Загрузить».
- Переименование/перемещение/удаление — правый клик по файлу в дереве (на телефоне — долгое нажатие).
- Удалённые файлы попадают в корзину на 14 дней.

## Просмотр и редактирование

- Клик по файлу открывает предпросмотр Markdown/изображения/PDF/DOCX/XLSX.
- Кнопка «Ред.» открывает встроенный редактор; `Ctrl+S` — сохранить.
- Черновики сохраняются в браузере, но после закрытия редактора без сохранения могут быть потеряны.
- Для совместной работы откройте один файл с двух устройств: правки синхронизируются автоматически.

## Поиск

- `Ctrl+K` — палитра команд.
- `Ctrl+Shift+F` или кнопка поиска — поиск по файлам, сообщениям, задачам и людям.
- Поиск учитывает права доступа и находит по имени/содержимому.

## Задачи

- В чате проекта вкладка «Проект» → «Задачи проекта».
- Введите «Новая задача…» и нажмите «+»; задача появится в «К выполнению».
- Кнопка-слои открывает канбан-доску с drag&drop.
- Двойной клик по карточке — редактирование (текст, исполнитель, приоритет, срок).

## Профиль и настройки

- Кнопка с человечком → «Профиль»: смена пароля, подписка, офлайн-режим, удаление аккаунта.
- «БАГ» — отправить баг-репорт со скриншотом.
- Тема переключается кнопкой солнца/луны в верхней панели.
