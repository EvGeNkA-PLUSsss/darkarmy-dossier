# Contributing

Спасибо, что хотите помочь DarkArmy Dossier.

## Как предложить изменение

1. Форкните репозиторий и создайте ветку от `main`.
2. Установите зависимости: `npm install`.
3. Перед PR: `npm run check && npm test`.
4. Опишите в PR:
   - что и зачем изменено;
   - как проверить;
   - скриншоты для UI (320/360/390 px для мобильных изменений);
   - риски и миграции, если есть.

## Стиль

- Node.js CommonJS, без сборки фронтенда.
- UTF-8, отступы 2 пробела, одинарные кавычки в JS.
- Не добавляйте зависимости без необходимости.
- Общие правила и карта кода — в [AGENTS.md](AGENTS.md).

## Безопасность

Не коммитьте `.env`, `data/`, `backups/`, ключи, сертификаты и дампы БД.
Об уязвимостях — см. [SECURITY.md](SECURITY.md).

## Лицензия

Отправляя PR, вы соглашаетесь, что ваш вклад распространяется под AGPL-3.0-only.
