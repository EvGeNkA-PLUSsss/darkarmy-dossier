## Что это такое

DarkArmy Dossier — **локальная (self-hosted) система командной работы с файлами**:

- проекты с ролевой моделью и приглашениями;
- дерево файлов и папок на диске сервера, предпросмотр и редактирование документов;
- чаты (общий, проектный, поддержка), задачи и канбан;
- локальный ИИ-ассистент **Darcus** через Ollama (RAG по файлам проекта, OCR/vision,
  генерация документов, голосовой ввод/озвучка);
- админ-панель: пользователи, приглашения, наказания, журнал, телеметрия, реклама,
  подписки, конфиг Darcus, баг-репорты, голос;
- PWA-оболочка и Electron-обёртка для настольного запуска.

Данные не уходят в облако: метаданные лежат в SQLite `data/dossier.db`, файлы проектов —
в каталоге `PROJECTS_ROOT`, ИИ работает на локальной Ollama. Внешние запросы есть только
у Darcus (DuckDuckGo HTML и API Википедии) и только если в конфиге заданы `webResults`/`wikiResults`.

## Ключевые факты

| Параметр | Значение | Где в коде |
|---|---|---|
| Версия | `1.1.0` | `package.json` |

| Web-фреймворк | Express **5.x** | `package.json`, `server.js` |

| Файлы проектов | обычная ФС, каталог `PROJECTS_ROOT` (по умолчанию `F:/Проекты`) | `config.js` |

| Реальное время | **SSE** (`GET /api/events`), WebSocket не используется | `server.js` |
| ИИ | Ollama (`/api/chat`, `/api/embeddings`, `/api/tags`, `/api/show`) | `darcus.js` |
| Голос | Silero TTS v5.6 RU (Python, порт 8765), faster-whisper / whisper.cpp, Web Speech API | `scripts/*.py`, `darcus.js`, `public/app.js` |
| Порт по умолчанию | `7561` (HTTP), опционально `HTTPS_PORT` (по умолчанию выключен) | `config.js` |
| Сессии | SQLite-таблица `sessions`, cookie `sid` (httpOnly, SameSite=strict) | `src/storage.js` |
| Тесты | `node:test` — 5 файлов, API-матрица безопасности | `test/` |
| Деплой | Caddy / nginx + systemd / PM2 / Планировщик Windows | `deploy/` |
| Десктоп | Electron 33 (`desktop/electron`), плюс `--app`-окно Edge/Chrome | `desktop/` |

## Возможности

### Проекты и доступ
- Проекты с папкой на диске (`PROJECTS_ROOT/<folder>`), создатель, участники, роли
  `creator` / `editor` / `member`.
- Создание проекта любым авторизованным пользователем; удаление — только администратор.
- Добавление участников и смена ролей создателем проекта или администратором.
- Инвайт-коды для регистрации, баны и мьюты, журнал действий с возможностью отката
  (`POST /api/revert/:id`) для правок, загрузок, создания, удаления, перемещения и переименования.
- Корзина проекта `.trash` с хранением 14 дней (настраивается константой `trashRetentionDays`).

### Файлы
- Дерево файлов и папок (`GET /api/tree`), скрытые элементы (начинающиеся с точки) не показываются.
- Создание `.md`, создание папок, переименование, перемещение (в том числе **между проектами**),
  загрузка файлов, удаление в корзину, восстановление.
- Предпросмотр Markdown, изображений, PDF, DOCX, XLSX (клиентские библиотеки в `public/vendor`).
- История версий с unified-diff и скачиванием версии (`GET /api/files/:projectId/history…`).
- Публичные share-ссылки `/s/<token>` с TTL (0–365 дней), отзывом и счётчиком обращений.
- Теги и «избранное» для файлов (`/api/projects/:projectId/tags|favorite`).
- Автоматическое обновление ссылок в Markdown при переименовании/перемещении файла
  (относительные ссылки, `/files/<pid>/<path>`, `<img src>`, `![[…]]`).

### Редактор
- Два режима: **модальный** редактор и **inline**-редактор в области просмотра.
- Markdown-тулбар (жирный, курсив, заголовки, список, код, таблица, ссылка, изображение, вложение).
- Превью в реальном времени, черновики в `localStorage` (`da_drafts`, `da_openEditors`),
  автосохранение в совместной сессии (debounce 500 мс на сервере).
- AI-кнопки над текстом: перефразировать, сократить, исправить, перевести (`POST /api/darcus/rewrite`).
- Совместное редактирование через SSE, индикатор «редактируют: …» и число устройств.
- Печать текущего файла (`Ctrl+P`).

### Поиск
- Гибридный поиск по проекту: keyword (имя/содержимое/OCR картинок) + семантика (эмбеддинги),
  ранжирование `0.5·kw + 0.5·sem + 0.15` при совпадении обоих.
- Поиск по всем доступным проектам (`GET /api/search-all`).
- Поиск по сущностям: проекты, сообщения общего и проектных чатов, задачи, люди
  (`GET /api/search/entities`), с учётом прав доступа.

### Общение
- Общий чат (режим «все» или «только администраторы»), удаление своих сообщений.
- Чат проекта, задачи в чате проекта, канбан-доска `todo/doing/done` с drag&drop,
  исполнителем, приоритетом, сроком и порядком.
- Поддержка (тикеты): один открытый тикет на пользователя, статусы `open/in_progress/closed`,
  системные сообщения, ответы поддержки.
- Запросы на изменение файла и жалобы на файл (видны администраторам).
- Вложения в чатах (до 25 МБ, чёрный список исполняемых расширений) с областями доступа
  `general` / `project:<id>` / `ticket:<id>`.
- Центр уведомлений (тикеты, запросы, жалобы, добавление в проект, @упоминания) + badge.

### Darcus (ИИ)
- Чат со стримингом (SSE поверх POST), RAG по файлам доступных проектов, интернет (DuckDuckGo)
  и Википедия, история диалога, «контекст израсходован на N%».
- ACTION-протокол: create / edit / mkdir / delete / move / rename с подтверждением
  (или режим «⚡ Авто»), результат показывается кликабельной плашкой.
- Генерация документов (`/api/darcus/generate-doc`) и отдельная кнопка «Darcus — создать».
- OCR и описание изображений vision-моделью, кэш по SHA-1 содержимого.
- Суммаризация документов (`/api/darcus/summarize`), стили ответа (presets).
- Голос: TTS (Silero/браузер), STT (faster-whisper / whisper.cpp / Web Speech),
  голосовой режим с краткими ответами и авто-отправкой.

### Админка и эксплуатация
- Дашборд: состояние системы, размеры БД/логов/кэшей/проектов/бэкапов, статус Ollama
  и наличие каждой модели, список бэкапов.
- Пользователи, приглашения, наказания, журнал изменений, настройки загрузки и общего чата.
- Телеметрия событий и клиентской информации.
- Реклама: слоты, картинки, round-robin распределение.
- Подписки «Dark Army Intelligence»: выдача, коды, отзыв.
- Конфиг Darcus (URL, модели, `numCtx`, `temperature`, таймаут, промпты) и переиндексация.
- Баг-репорты: приём со скриншотом, просмотр, редактирование текста/скриншота, удаление.
- Голос: настройки STT/TTS, установка faster-whisper, запуск Silero.
- Бэкапы: `npm run backup`, кнопка в админке, задачи Планировщика/cron, экспорт и импорт метаданных.

## Быстрый старт

### Windows (короткий путь)

```powershell
cd F:\DarkArmy\DarkArmyDossier
npm install
Copy-Item .env.example .env
# отредактируйте .env: SESSION_SECRET, PROJECTS_ROOT
node --env-file=.env server.js
```

Либо просто запустите `start.bat` — он создаст локальный `.env` со случайным
`SESSION_SECRET`, если файла ещё нет, и запустит сервер.

Откройте `http://127.0.0.1:7561`. Первый запуск создаёт администратора `admin`:

- если задан `ADMIN_PASSWORD` — пароль берётся оттуда;
- иначе случайный пароль печатается **в консоль** (в лог не пишется).

Смените пароль после первого входа (Профиль → сменить пароль).

### Linux/macOS

```bash
npm ci --omit=dev
cp .env.example .env
node --env-file=.env server.js
```

### Минимальный `.env`

```ini
NODE_ENV=production
PORT=7561
BIND_HOST=127.0.0.1
SESSION_SECRET=<64 hex-символа>
PROJECTS_ROOT=/srv/darkarmy-projects
TRUST_PROXY=false
```

Полный разбор переменных — [02-installation.md](02-installation.md).

## Ограничения проекта (кратко)

1. **Один процесс Node.** SSE-клиенты и сессии редактирования хранятся в памяти процесса,
   SQLite один. Горизонтальное масштабирование не предусмотрено.
2. **Нет WebSocket.** Всё реальное время — SSE; «печатает…» и курсоры не передаются.
3. **Совместное редактирование — last-write-wins**, без OT/CRDT и без разрешения конфликтов.
4. **Микрофон** браузер даёт только в secure context: `localhost` или HTTPS.
   Для LAN есть встроенный HTTPS-порт (`HTTPS_PORT`) и fallback через системный диктофон.
5. **Darcus требует Ollama** и скачанных моделей. Без них работает всё остальное,
   а в админке виден статус моделей.
6. **Нет MFA/SSO**, нет аудита внешними средствами, нет API-токенов для интеграций.
7. **Подписка** (`subscription-required`) ограничивает чат Darcus, rewrite, summarize,
   generate-doc и анализ изображений; TTS/STT и стили доступны без подписки.
8. **ACTION-тип `generate_doc`** поддерживается клиентским парсером (`public/app.js`,
   `AI_ACTION_TYPES`) и добавляется в системный промпт runtime-блоком `FILE_PROMPT`
   из `darcus.js`. В поставляемом `data/ai-config.json` текст `system` перечисляет
   только `create/edit/mkdir/delete/move/rename` — для более уверенного использования
   добавьте `generate_doc` в `system` (админка → Darcus → Промпты).
9. **Реклама** — локальные картинки из `data/ads`; внешних рекламных сетей нет.
10. **APK** в репозитории не собирается: есть PWA-манифест и service worker,
    инструкция по Bubblewrap/TWA приведена в [09-desktop-mobile-pwa.md](09-desktop-mobile-pwa.md),
    но готового Android-проекта нет ❌.
